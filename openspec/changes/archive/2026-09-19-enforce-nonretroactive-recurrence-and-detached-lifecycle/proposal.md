## Why

Recurring-series generator changes can still be applied in place after occurrence state exists, which rewrites the meaning of historical occurrences and can strand their state. Detached occurrence states are now visible, but the occurrence mutation paths reject them because their anchor is no longer generated by the truncated series.

## What Changes

- Prevent an existing recurring series with persisted occurrence state from changing its recurrence status, recurrence rule, or schedule through an in-place base-task update.
- Continue to allow in-place correction of those generator fields while the series has no persisted occurrence state.
- Require stateful series to use the existing following-series or truncation operations for generator changes.
- Allow detached occurrences to be updated, completed, and reopened using their persisted identity without requiring the current RRULE to generate their anchor.
- Keep a reopened detached completion materialized and detached when it has no field overrides, because deleting its state would make the occurrence disappear.
- Treat deletion of an open detached occurrence as removal of its standalone state rather than persistence of a detached `SKIPPED` state.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `task-update-contract`: constrain in-place recurring-series generator changes once occurrence state exists.
- `task-occurrence-lifecycle`: define supported mutation and reopening behavior for detached occurrences.
- `explicit-task-mutations`: define deletion semantics for an occurrence whose state is detached.

## Impact

- Task mutation routing and recurring-series validation in the backend service layer.
- Sparse occurrence-state lookup and detached-state transitions.
- Unit tests for base-series replacement, partial MCP updates, and detached occurrence lifecycle.
- No new endpoint or request shape is introduced; callers receive a client error when they attempt an unsafe in-place generator change and can use the existing following-series or truncation operation.
