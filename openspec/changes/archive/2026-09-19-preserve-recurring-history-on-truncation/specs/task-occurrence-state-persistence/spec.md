## ADDED Requirements

### Requirement: Occurrence state stores detached classification

Persisted recurring-occurrence state SHALL contain a non-null detached classification. Attached state SHALL default to `false`; state preserved after its anchor leaves the generated span of its series SHALL store `true` while retaining its `seriesId` and `occurrenceScheduledAt` identity.

#### Scenario: Persist ordinary occurrence state
- **WHEN** the system materializes state for an occurrence still generated by its series
- **THEN** the state SHALL persist `detached: false`

#### Scenario: Persist stranded meaningful state
- **WHEN** truncation strands completed or modified occurrence state
- **THEN** the state SHALL persist `detached: true`
- **AND** its series and occurrence identities SHALL remain unchanged

### Requirement: Existing orphaned state is migrated consistently

The detached-state migration SHALL classify state already orphaned by a prior series truncation. Completed and modified state at or beyond the stored series end SHALL become detached, while skipped state in the same range SHALL be removed.

#### Scenario: Migrate a pre-existing orphaned completion or modification
- **WHEN** existing completed or modified occurrence state is anchored outside its truncated series
- **THEN** the migration SHALL retain it and set `detached` to true

#### Scenario: Migrate a pre-existing orphaned skip
- **WHEN** existing skipped occurrence state is anchored outside its truncated series
- **THEN** the migration SHALL delete it
